# Ploby 디자인 시스템

Ploby는 외주 프로젝트의 약속과 대금을 관리한다. 사용자는 먼저 **지금 확인할 일**을 이해하고, 필요한 만큼 세부 내용을 연다.

## 정보 구조

- 홈: 확인 요청 한 줄, 검색·상태 필터, 프로젝트 목록. 목록에는 이름·상태·상대방·총예산만 표시한다. 예치·예약·지급·잔액을 모두 반복하지 않는다.
- 프로젝트 요약: 예약된 대금, 지급 완료·가용 잔액, 가까운 기한의 할 일 최대 3개. 전체 할 일은 더 보기, 전체 회계는 자금 내역 대화상자로 연다.
- 작업·경비·계약·변경 요청·기록·관리: 실제 내용을 전환하는 메뉴. URL의 `tab`으로 상태를 보존한다. 내부 링크는 대상 탭과 접힌 항목을 함께 열고 포커스를 옮긴다.
- 작업·경비·변경 요청: 제목·상태가 보이는 목록. 선택한 항목의 근거, 문서, 기한, 액션을 펼친다.
- 프로젝트 생성: 기본 정보 → 경비 규칙 → 작업과 대금 → 확인 및 생성. 뒤로 가도 입력은 유지한다. 마지막 단계의 오류를 누르면 해당 단계로 돌아간다.
- 데모 시계: 상단 ‘데모 도구’에서 연다. 항상 보이는 데모 표시와 하단 안내로 실제 자금이 아님을 알린다.
- 주소·해시·구현 정보: 관리 및 서비스 안내에서 확인한다. 서명·지급 확인창의 근거와 기한은 유지한다.

## 토큰

소스: `frontend/src/tokens.css`. 기본 색상 → 의미별 색상 → 컴포넌트 속성으로 연결한다. 역할 전환으로 브랜드 색을 바꾸지 않는다.

| 영역 | 규칙 |
| --- | --- |
| 색상 | 흰색·중성 회색·차콜 중심. 주요 행동은 명도 대비로 강조. 성공·주의·오류에만 아주 낮은 채도의 색을 쓰고 텍스트를 함께 표시 |
| 서체 | 시스템 한글 산세리프. 외부 폰트 요청 없음. 본문 15px, 입력 16px, 보조 12–13px, 섹션 20px, 제목 32px |
| 숫자 | 금액과 기한에 tabular numbers. 금액과 ‘원’의 크기를 구분 |
| 간격 | 4px 단위. 주 간격 16 / 24 / 32 / 48px. 최대 콘텐츠 폭 1040px |
| 모서리 | 패널 20px, 버튼 12px, 보조 요소 10px. 과도한 그림자·장식 그라데이션 없음 |
| 입력 | 최소 높이 48px. 라벨 상시 표시. 포커스 테두리와 안내·오류 상태 |
| 버튼 | 기본 높이 44px, 주요 생성 행동 48px. 채움·보조·위험·텍스트 버튼 구분 |
| 아이콘 | `Icon.tsx`의 일관된 선형 SVG. 장식 아이콘은 접근성 트리에서 제외 |
| 동작 | 피드백 140ms, 화면·대화상자 진입 200ms. opacity·transform만 애니메이션 |

## 접근성과 반응형

- 색상은 OS의 라이트·다크 설정을 따른다. 두 모드의 의미별 토큰을 따로 정의한다.
- `prefers-reduced-motion`이면 애니메이션과 부드러운 스크롤을 끈다.
- 키보드 포커스, 본문 바로가기, 라벨, 선택 상태를 제공한다.
- 대화상자는 포커스를 가두고 Escape로 닫으며, 닫힌 뒤 호출한 버튼에 포커스를 돌려준다. 위험 행동 버튼에 초기 포커스를 주지 않는다.
- 메뉴는 링크, 필터는 pressed 버튼, 단일 선택은 방향키를 지원하는 radio group으로 구현한다.
- 모바일에서 프로젝트 요약과 금액은 세로로 쌓는다. 탭만 가로로 스크롤하고 문서 전체가 가로로 넘치지 않게 한다.
- 모바일 입력은 16px로 유지하고, 고정 요소와 대화상자는 안전 영역을 고려한다.

## 구현 경계

백엔드의 정책·역할별 액션·회계 계산은 그대로 사용한다. 예시 지표나 가짜 활동을 추가하지 않는다. 화면 검증용 `?fixture=1`은 기존 fixture를 사용하며 실제 행동을 실행하지 않는다.
