The implemented function is bounded AI-assisted purchasing for client-funded project work. Kiln plans the offers and interprets vendor documents; deterministic code makes the authorization decision; Monad testnet escrow handles reservations and transfers. ## Reproduce without API credentials

```sh
python3 -m escrow.audit evidence/projects/pd4466e964c56/log.jsonl --data evidence
python3 -m escrow.audit evidence/projects/p7ccf1ec48ac6/log.jsonl --data evidence
python3 harness/benchmark_submission.py --verify evidence/benchmark.json
python3 harness/usage_report.py --log evidence/usage.jsonl --md
```

Audit exit 2 means incomplete; it is expected for demo authorization. Exit 0 means verified and 1 means inconsistent. Add `--offline` to the auditor to omit RPC; the chain is then explicitly unchecked. Each downloaded ZIP can instead be unzipped and checked with `python3 verify.py`. Wallet-mode archives require `pip install -r requirements.txt`.
