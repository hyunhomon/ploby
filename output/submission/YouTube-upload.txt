DESCRIPTION
Ploby keeps an AI purchasing agent's requests within a client-funded project policy and records every approval and stop.

This 2:49 demonstration shows:
00:00 Agreed project scope and budget
00:10 Kiln qwen3-32b planning and adaptation after a blocked offer
00:40 Purchase report, receipt review and completed testnet settlement
01:21 Boundary run 1: an unlisted vendor
01:42 Boundary run 2: purchase total over the cap
01:58 Both stops in the audit, with matching public-chain events
02:08 Human pause and the stopped task
02:24 Independent evidence and inference efficiency

The two boundary runs use a fresh project with the same spending limits, so previous document allocations do not mask the tested rules. Both plans call Kiln live; previously read quote documents use the local response cache. The UI and logs distinguish these cases.

Test environment: Monad testnet (10143), TestKRW. No real funds. Role approvals in the filmed run use public demo HMAC keys, so the verifier correctly reports partial human-approval verification. Optional EIP-712 approvals are checked by the off-chain engine; the deployed contract still trusts its operator for business-rule decisions. The demo clock is advanced by three days; blockchain timestamps use real testnet time.

The recording is trimmed for time. Clips accelerated to 1.25x or 1.4x are labeled; still captures are labeled. English captions are burned into the video. No voiceover.
